# Package: existing results + best-paper outline + dataset cache

This package consolidates:
1) The original reproducible MarketSim experiment code and outputs (CSV + figures).
2) A best-paper style paper outline (V4) that upgrades the core model to Transformer/variants.
3) A cached dataset (hard suite episodes) generated by the included code with seed=7.

## Structure
- existing_results/csv: reported metrics tables
- existing_results/figures: plots from the original run
- code/marketsim_ed_adaptiveshare_experiments.py: self-contained reproduction script
- datasets/: cached episodes saved as .npz (see below)
- paper/BestPaper_Outline_V4.md: upgraded outline with Transformer/variants

## Reproduce original results
From the package root:
```bash
python code/marketsim_ed_adaptiveshare_experiments.py
```

The script now also produces high-quality visualizations (bar chart, heatmap, and a sample
episode plot) under `results_viz/`. Use `--no-viz` to skip, or `--viz-dir` to customize
the output directory.

## Dataset cache
The file `datasets/marketsim_hard_suite_seed7.npz` stores 4 families × 80 episodes each, with:
- y: target series (float32)
- regimes: regime labels (int16)
- cps: change points (variable-length arrays, stored as object)
- expert_preds: expert predictions (float32)
- losses: bounded losses in [0,1] (float32)
- oracle_pi: DP oracle expert path for S=10 (int16)
- oracle_L: oracle cumulative loss (float32)
